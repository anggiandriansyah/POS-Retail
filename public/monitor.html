2. What Could Be Improved (Evaluasi Diri & Celah Proses)

Refleksi Jujur Tim
[DevOps & Release Engineering] Keterlambatan Sinkronisasi Konstanta APP_VERSION RESOLVED

Fakta Lapangan: Saat rilis awal di-push ke cloud Vercel, teks header di layar login sempat masih tertulis v1.4.0 karena konstanta pada src/utils/format.ts belum dinaikkan ke 2.0.0 sebelum ditegur oleh Mas Gege.
Akar Masalah: Proses version bump dilakukan secara manual dan terpisah dari pipeline commit master scope.
Solusi Konkret: Wajib membuat automated release script (npm run bump:version) yang menyinkronkan package.json, format.ts, dan metadata header dalam satu perintah tunggal.

[Cloud Auth & Superadmin Access] Jeda Ketersediaan Akun Superadmin di Cloud DEV & PROD RESOLVED

Fakta Lapangan: Mas Gege sempat mendapati notifikasi "username tidak ditemukan" saat mencoba login admindev / adminprod di Vercel.
Akar Masalah: Logika penanganan superadmin bypass sudah aktif di code lokal, namun push git ke GitHub/Vercel belum terpicu otomatis hingga Mas Gege memberi instruksi langsung.
Solusi Konkret: Standar Operasional Prosedur (SOP) deployment harus mewajibkan push commit otomatis segera setelah approval dokumen selesai di Live Monitor.

[Approval Workflow] Sinkronisasi Status Monitor Step 6 RESOLVED

Fakta Lapangan: Step 6 di pipeline monitor sempat kembali ke status "Sedang Berjalan" saat halaman di-refresh sebelum di-lock permanen.
Akar Masalah: Default fallback state JavaScript monitor membaca template awal sebelum membaca status persetujuan localStorage.
Solusi Konkret: State persistensi status pipeline kini dikunci permanen pada HTML statis setelah deployment production dinyatakan rilis.
