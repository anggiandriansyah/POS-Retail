4. Analisis Risiko & Rencana Pemulihan (Rollback Plan)

Untuk mengantisipasi keadaan darurat pada operasional toko, telah disiapkan prosedur pemulihan bencana sebagai berikut:

  • Karakteristik Migrasi Database: Seluruh penambahan skema pada v1_3_0_store_settings_discounts_tax.sql bersifat additive (penambahan tabel store_settings dan penambahan kolom baru dengan nilai default). Data transaksi lama tidak ada yang dihapus atau diubah formatnya.
  • Prosedur Rollback Aplikasi (Jika Diperlukan):
    1. Kembalikan pointer Git branch main ke commit versi sebelumnya (4ebd1cc76e4f36d927a6bdbb6f38b2f281f7b6df - v1.2.0).
    2. Vercel akan secara otomatis melakukan auto-build dan mendistribusikan versi 1.2.0 dalam waktu kurang dari 30 detik.
    3. Database tetap kompatibel dan tidak akan mengalami crash karena skema 1.3.0 mendukung penuh kode versi 1.2.0.
