Buku Panduan Pengguna ALPHOS by AlphaGen v1.4.0

Panduan operasional aplikasi Web & Mobile Android untuk Kasir dan Owner/Admin

1. Akses Web & Aplikasi Mobile

  • Web DEV: https://alphos-develop-anggiandriansyah.vercel.app/
  • Mobile Android (Expo / React Native): Terhubung langsung ke Supabase DEV tcbhaiyhtndnqgatysmh.

2. Panduan Kasir / User

  • Shift & Petty Cash: Buka shift dengan modal awal, catat kas masuk/keluar (5 kategori terlokalisasi), dan tutup shift untuk rekonsiliasi.
  • Kasir & Scanner: Scan barcode via kamera HP/Web atau input manual, atur diskon item/nota dan PPN, pilih pembayaran Cash/QRIS/Transfer, lalu bagikan struk via WhatsApp atau cetak Bluetooth Thermal (58mm/80mm).

3. Panduan Owner / Admin

  • Live Monitor: Pantau omzet, stok menipis, dan setujui/tolak permintaan stok kasir secara real-time di Web & Mobile.
  • Pengaturan Toko & Laporan CSV: Atur profil toko dinamis dan ekspor laporan penjualan/mutasi stok ke Excel (UTF-8 BOM).
