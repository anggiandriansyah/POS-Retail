2. Rincian Perubahan Per Versi

Versi 1.3.0 — Fitur Promo/Diskon, Pajak, Pengaturan Toko Dinamis & Export CSV (Terkini)

Tanggal Rilis: 24 November 2026 | Lingkungan: DEV & PRODUCTION

  • Pengaturan Profil Toko Dinamis (US-3.1):
    • Tabel baru public.store_settings (singleton id = 1) menyimpan nama toko, alamat, telepon, catatan footer struk belanja, dan tarif pajak default.
    • Form interaktif Pengaturan Toko untuk Owner/Admin dengan sinkronisasi langsung ke Supabase Realtime.
    • Struk digital publik (/receipt/[invoice]) secara otomatis menampilkan identitas toko dinamis dari tabel tersebut.
  • Diskon Fleksibel & Pajak PPN (US-3.2):
    • Diskon Per Item: Kasir dapat memberikan diskon nominal (Rp) atau persentase (%) pada setiap baris belanjaan.
    • Diskon Nota / Order Global: Diskon tambahan di tingkat total belanja (nominal atau persentase).
    • Opsi Pajak PPN: Kotak centang (toggle) untuk menerapkan PPN secara opsional (default 11%).
    • Perhitungan sisi server tervalidasi pada RPC process_sale (7 parameter) yang kebal manipulasi client-side.
  • Filter Laporan & Export Data ke Excel/CSV (US-3.3):
    • Filter rentang tanggal (Start Date dan End Date) pada riwayat transaksi penjualan dan riwayat mutasi stok barang.
    • Tombol Export Penjualan (CSV) dan Export Mutasi Stok (CSV) menggunakan modul src/utils/csv.ts yang memenuhi standar RFC-4180, dilengkapi UTF-8 BOM agar langsung rapi dibuka di Microsoft Excel, dan proteksi dari CSV formula injection (karakter =, +, -, @).
  • Kompatibilitas Dual-Role (Admin/User & Owner/Kasir):
    • Sistem mendukung 4 role: owner, admin, kasir, user melalui fungsi helper isAdminRole() dan constraint database. Akun lama tetap berjalan normal tanpa perlu migrasi ulang.
  • Kesiapan Mobile React Native (US-3.4):
    • Pembersihan aset warisan Vite dan isolasi modul shared core (src/types/pos.ts, src/utils/format.ts, src/utils/pricing.ts, src/utils/csv.ts, src/i18n/translations.ts) agar murni bebas DOM, siap diimpor langsung oleh aplikasi React Native di Sprint 4.

Versi 1.2.0 — Modernisasi Next.js 16, TypeScript, Live Realtime & Barcode Scanner

Tanggal Rilis: 24 November 2026

  • Migrasi Arsitektur Penuh: Konversi total dari Single Page Application (Vite) ke Next.js 16.4.6 App Router dengan compiler Turbopack dan strict TypeScript.
  • Fleksibilitas Autentikasi: Login kasir/owner dapat menggunakan @username atau email. Registrasi mandiri mendukung Google OAuth (Google Cloud Console) dan form email/password.
  • Bilingual (ID/EN) & Mode Tampilan: Fitur pergantian bahasa Indonesia/Inggris instan dan Dark/Light Mode berbasis localStorage.
  • Pemantauan Toko Realtime: Dashboard Live Monitor bagi Owner untuk melihat transaksi berjalan, stok habis, permintaan restock dari kasir (stock requests), dengan aksi 1-klik Approve / Reject / Restock.
  • Peningkatan Scanner Barcode: Integrasi BarcodeDetector API dengan continuous autofocus, mode Photo Scan (unggah foto/gambar kemasan), dan pemindai langsung pada form penambahan produk baru.

Versi 1.1.0 — Autentikasi, Pemisahan Peran, Shift Kasir & Petty Cash

Tanggal Rilis: 24 November 2026

  • Penerapan Supabase Auth dan penguncian RLS (Row Level Security) ketat pada seluruh tabel operasional (role anon diblokir total dari tabel produk, transaksi, dan shift).
  • Siklus Buka/Tutup Shift Kasir: pencatatan modal awal, rekonsiliasi kas akhir, serta fitur Force Close oleh Owner.
  • Pencatatan kas operasional toko (Petty Cash) dengan tipe kas masuk (IN) dan kas keluar (OUT).
  • Struk digital publik yang aman melalui RPC get_public_receipt tanpa membocorkan data sensitif toko.

Versi 1.0.0 — Fondasi MVP Kasir Retail

Tanggal Rilis: Awal November 2026

  • Pencatatan katalog produk, harga beli, harga jual, barcode, dan stok fisik.
  • Form kasir sederhana: tambah item ke keranjang, hitung total belanja, kalkulasi uang bayar dan kembalian.
  • Tampilan cetak struk nota belanja sederhana via browser print.

3. Panduan Peningkatan / Upgrade Path

Prosedur Upgrade ke v1.3.0:
1. Jalankan migrasi SQL supabase/migrations/v1_3_0_store_settings_discounts_tax.sql pada Supabase project.
2. Pastikan tabel public.app_versions mencatat record 1.3.0.
3. Deploy kode aplikasi branch main ke Vercel.
4. Pengguna tidak perlu menghapus cache lokal; sesi login dan shift aktif akan tetap dipertahankan.
